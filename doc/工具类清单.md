## 1. d3code-common-core 模块

### 1.1 StringUtils - 字符串工具类

**位置**: `com.alphay.boot.common.core.utils.StringUtils`

**功能说明**: 提供字符串操作的常用方法，继承自 Apache Commons Lang3 的 StringUtils

**主要方法**:

| 方法名                                                                           | 说明                            |
|-------------------------------------------------------------------------------|-------------------------------|
| `blankToDefault(String str, String defaultValue)`                             | 获取参数不为空值，为空则返回默认值             |
| `isEmpty(String str)`                                                         | 判断字符串是否为空串                    |
| `isNotEmpty(String str)`                                                      | 判断字符串是否为非空串                   |
| `trim(String str)`                                                            | 去除字符串首尾空格                     |
| `substring(String str, int start)`                                            | 从指定位置截取字符串                    |
| `substring(String str, int start, int end)`                                   | 截取指定范围的字符串                    |
| `format(String template, Object... params)`                                   | 格式化文本，{} 表示占位符                |
| `ishttp(String link)`                                                         | 判断是否为 http(s):// 开头           |
| `str2Set(String str, String sep)`                                             | 字符串转Set集合                     |
| `str2List(String str, String sep, boolean filterBlank, boolean trim)`         | 字符串转List集合                    |
| `containsAnyIgnoreCase(CharSequence cs, CharSequence... searchCharSequences)` | 判断字符串是否包含指定字符串列表中的任意一个（忽略大小写） |
| `toUnderScoreCase(String str)`                                                | 驼峰转下划线命名                      |
| `inStringIgnoreCase(String str, String... strs)`                              | 判断字符串是否包含在指定字符串数组中（忽略大小写）     |
| `convertToCamelCase(String name)`                                             | 下划线大写方式命名的字符串转换为驼峰式（首字母大写）    |
| `toCamelCase(String s)`                                                       | 下划线转驼峰式命名                     |
| `matches(String str, List<String> strs)`                                      | 判断字符串是否匹配指定字符串列表中的任意一个        |
| `isMatch(String pattern, String url)`                                         | 判断url是否与规则配置匹配（支持 ?、*、**）     |
| `padl(Number num, int size)`                                                  | 数字左边补齐0，使之达到指定长度              |
| `padl(String s, int size, char c)`                                            | 字符串左补齐指定字符                    |
| `splitList(String str)`                                                       | 切分字符串（分隔符默认逗号）                |
| `splitList(String str, String separator)`                                     | 切分字符串                         |
| `splitTo(String str, Function mapper)`                                        | 切分字符串并自定义转换（分隔符默认逗号）          |
| `splitTo(String str, String separator, Function mapper)`                      | 切分字符串并自定义转换                   |
| `startsWithAnyIgnoreCase(CharSequence str, CharSequence... prefixs)`          | 检查字符串是否以指定前缀开头（忽略大小写）         |
| `convert(String input, Charset fromCharset, Charset toCharset)`               | 将字符串从源字符集转换为目标字符集             |

**位置**: `com.alphay.boot.common.core.utils.DateUtils`

**功能说明**: 提供日期时间处理的常用方法，继承自 Apache Commons Lang3 的 DateUtils

**主要方法**:

| 方法名                                                                            | 说明                                   |
|--------------------------------------------------------------------------------|--------------------------------------|
| `getNowDate()`                                                                 | 获取当前日期和时间的 Date 对象                   |
| `getDate()`                                                                    | 获取当前日期的字符串表示，格式为 YYYY-MM-DD          |
| `getCurrentDate()`                                                             | 获取当前日期的字符串表示，格式为 yyyyMMdd            |
| `datePath()`                                                                   | 获取当前日期的路径格式字符串，格式为 "yyyy/MM/dd"      |
| `getTime()`                                                                    | 获取当前时间的字符串表示，格式为 YYYY-MM-DD HH:MM:SS |
| `getTimeWithHourMinuteSecond()`                                                | 获取当前时间的字符串表示，格式为 "HH:MM:SS"          |

| `dateTimeNow(FormatsType format)`                                              | 获取当前日期和时间的指定格式的字符串表示                 |
| `formatDate(Date date)`                                                        | 将日期格式化为 YYYY-MM-DD 格式的字符串            |
| `formatDateTime(Date date)`                                                    | 将日期格式化为 YYYY-MM-DD HH:MM:SS 格式的字符串   |
| `parseDateToStr(FormatsType format, Date date)`                                | 将日期按照指定格式进行格式化                       |
| `parseDateTime(FormatsType format, String ts)`                                 | 将指定格式的日期时间字符串转换为 Date 对象             |
| `parseDate(Object str)`                                                        | 将对象转换为日期对象（支持多种格式）                   |
| `getServerStartDate()`                                                         | 获取服务器启动时间                            |
| `difference(Date start, Date end, TimeUnit unit)`                              | 计算两个时间之间的时间差（绝对值）                    |
| `getDatePoor(Date endDate, Date nowDate)`                                      | 计算两个日期之间的时间差，返回"天 小时 分钟"格式           |
| `getTimeDifference(Date endDate, Date nowDate)`                                | 计算两个时间点的差值（天、小时、分钟、秒），当值为0时不显示       |
| `toDate(LocalDateTime temporalAccessor)`                                       | 将 LocalDateTime 对象转换为 Date 对象        |
| `toDate(LocalDate temporalAccessor)`                                           | 将 LocalDate 对象转换为 Date 对象            |
| `validateDateRange(Date startDate, Date endDate, int maxValue, TimeUnit unit)` | 校验日期范围是否合法                           |
